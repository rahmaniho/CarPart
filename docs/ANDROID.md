# مستندات نرم‌افزار اندروید قطعه‌رسان (Android Application Guide)

اپلیکیشن اندروید **قطعه‌رسان (`قطعه‌رسان — CarPart`)** در دو لایه مکمل مهندسی در این مخزن پیاده‌سازی و تحویل شده است تا هم بسته نصبی آماده نصب روی گوشی‌های واقعی اندروید (`.apk`) در دسترس باشد و هم کد منبع بومی React Native / Capacitor برای توسعه آتی کاملاً یکپارچه بماند.

---

## ۱. معماری دوگانه موبایل در Monorepo

### الف) پروژه اندروید بومی Capacitor + Gradle (`apps/web/android` — شناسه بسته: `ir.carpart.app`)
- شامل تمام امکانات کامل نسخه وب راست‌به‌چپ فارسی (هر ۴ پنل تخصصی **مکانیک، فروشنده، پیک، مدیر/اپراتور**، فونت محلی `Vazirmatn`، نمودارها، سبد تک‌فروشنده‌ای، درگاه آزمایشی شفاف و ردیابی OTP) در قالب پوسته بومی اندروید (`Android SDK 24..36`).
- **یکپارچگی‌های بومی سیستم‌عامل اندروید (`src/lib/native-bridge.ts`)**:
  - مدیریت دکمه بازگشت سخت‌افزاری اندروید (`Hardware Back Button`) در تاریخچه صفحات.
  - تنظیم رنگ نوار وضعیت بالای گوشی (`StatusBar: #115E59`).
  - دریافت مختصات دقیق **GPS سخت‌افزاری گوشی** برای پنل پیک ناوگان (`@capacitor/geolocation`).
  - پایش آنی قطع و وصل شبکه موبایل (`@capacitor/network`) و نمایش نوار هشدار آفلاین.
  - نوار ناوبری پایین صفحه ویژه موبایل (`MobileBottomNav`) منطبق با ناحیه امن نمایشگر (`Safe Area`).
  - **پنجره تنظیم زنده سرور اتصال (`ServerConnectionModal`)**: پیش‌فرض متصل به سرور ابری فعال، به همراه امکان تغییر آنی به شبیه‌ساز اندروید (`http://10.0.2.2:4000`)، شبکه محلی کارگاه (`http://192.168.x.x:4000`) یا دامنه عملیاتی به همراه دکمه **تست زنده پینگ و سلامت پایگاه‌داده**.

### ب) اپلیکیشن بومی React Native / Expo (`apps/mobile` — شناسه بسته: `ir.carpart.mobile`)
- پیاده‌سازی‌شده با کامپوننت‌های بومی `react-native` و اشتراک مستقیم بسته `@carpart/contract` (بدون تکرار منطق تومان، جلالی، نرمال‌ساز فارسی یا وضعیت‌ها).
- پوشش مستقیم جست‌وجوی کاتالوگ، سبد خرید، ثبت استعلام (RFQ)، پنل‌های نقش‌محور مکانیک/فروشنده/پیک/مدیر و تغییر سرور API.
- بررسی خودکار انواع TypeScript (`npm run typecheck`) و بررسی انطباق ۱۰۰٪ مسیرها با کنترلرهای بک‌اند (`npm run check:contract`).

## ۲. فایل نصبی آماده اندروید (`.apk`)

بسته نصبی امضاشده دیجیتال (**V1 + V2 + V3 Signed APK**) توسط خط لوله خودکار Gradle در مسیر زیر تولید و آماده نصب مستقیم روی گوشی‌های اندروید ۷.۰ به بالا (`Android 7.0 – Android 16`) است:

- مسیر فایل نصبی در محیط کار: `releases/carpart-v0.1.0-release.apk`
- نام نمایشی روی صفحه اصلی گوشی: **قطعه‌رسان**
- آیکون تطبیقی (Adaptive Icon): نشان برداری اختصاصی چرخ‌دنده و آذرخش قطعه‌رسان به رنگ سبز تیره صنعتی (`#0F766E`) و کهربایی (`#F59E0B`).

## ۳. دستورات ساخت محلی و CI/CD

### ساخت محلی با Android Studio / Gradle (نیازمند JDK 21 و Android SDK)
```bash
# همگام‌سازی آخرین بیلد رابط کاربری و افزونه‌های بومی با پروژه اندروید
npm run android:sync

# ساخت فایل APK امضاشده
npm run android:apk
# خروجی: apps/web/android/app/build/outputs/apk/release/app-release.apk
```

### اجرای نسخه React Native با Expo
```bash
npm run start -w @carpart/mobile
```

### خط لوله خودکار GitHub Actions
فایل `.github/workflows/android.yml` در هر Push به صورت خودکار:
1. محیط Node.js 22، Temurin JDK 21 و Android SDK 36 را آماده می‌کند.
2. فرمان `npm run android:sync` و `./gradlew assembleRelease` را اجرا می‌نماید.
3. صحت امضای دیجیتال APK را با ابزار رسمی `apksigner verify` راستی‌آزمایی کرده و خروجی `carpart-v0.1.0-release.apk` را منتشر می‌کند.
