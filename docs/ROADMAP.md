# نقشه راه — کارپارت

## نسخه ۱.۱ (اولویت بالا)
- **کامپایل و انتشار APK** (دو Flavor) + طراحی نهایی آیکون/اسپلش
- **اعلان Push (FCM)** برای مکانیک/پیک — جایگزین polling اعلان‌ها
- **مهاجرت baseline پایگاه‌داده PostgreSQL** برای استقرار تولید
- **سخت‌سازی CSP** در reverse proxy + بررسی نفوذ

## نسخه ۱.۲
- **سفارش چندفروشنده‌ای** (parent order + sub orders — ساختار داده آماده است)
- **نقشه واقعی** (Neshan/OSRM) برای ETA و فاصله مسیر در UI موبایل
- **پنل کامل مکانیک در وب** (خودروها/نشانی‌ها/درخواست‌ها — اکنون در موبایل)
- نظرات/امتیازدهی کامل‌تر + نمایش عمومی در کارت‌ها

## نسخه ۲
- مصرف‌کننده نهایی و ناوگان (fleet)، اشتراک‌ها، پرداخت اقساطی
- گارانتی الکترونیک قطعات، استعلام اصالت
- هوش مصنوعی در پیشنهاد قطعه (بر اساس سابقه خودرو/تعمیرات)
- چندزبانگی (کردی/عربی) + دسترس‌پذیری AA

## اصول ثابت
- شفافیت رتبه‌بندی (بدون رتبه مخفی بر اساس کمیسیون) حفظ می‌شود
- هر ویژگی جدید باید تست‌شده باشد تا «عملیاتی» اعلام شود
