# جریان‌های کاربری — کارپارت

## ۱. مکانیک — خرید مستقیم
۱. ورود با OTP/رمز → پوسته مکانیک (اپ موبایل) یا وب
۲. جست‌وجوی قطعه (تحمل املای فارسی) → کارت پیشنهادها با **رتبه‌بندی شفاف** و هشدار سازگاری
۳. «خرید مستقیم» → ثبت سفارش (قیمت از سرور، رزرو موجودی)
۴. پرداخت (Sandbox در این استقرار) → وضعیت PAID
۵. پیگیری تاریخچه وضعیت تا تحویل (کد OTP به پیک) → تکمیل/نظر

## ۲. مکانیک — درخواست قیمت (RFQ)
۱. ثبت درخواست (عنوان، تعداد، فوریت، خودرو، نشانی، مهلت)
۲. درخواست برای فروشندگان مرتبط ارسال می‌شود
۳. فروشندگان پیشنهاد ثبت می‌کنند → مکانیک **نمای مقایسه** با امتیاز و عوامل آن را می‌بیند
۴. پذیرش پیشنهاد → سفارش ساخته می‌شود، سایر پیشنهادها DECLINED، درخواست CONVERTED
۵. بدون پذیرش تا مهلت → EXPIRED/UNFULFILLED

## ۳. فروشنده
۱. ثبت‌نام → تکمیل پروفایل/شعبه → «ارسال برای تأیید»
۲. پس از تأیید مدیر: ثبت محصول (قیمت/موجودی/کیفیت)، پاسخ به RFQها
۳. مدیریت سفارش‌ها: تأیید → آماده‌سازی → «آماده تحویل به پیک»
۴. مشاهده کمیسیون و تسویه‌ها در پنل مالی

## ۴. پیک
۱. ثبت‌نام → تأیید مدیر → «آنلاین» + ارسال موقعیت
۲. دریافت پیشنهاد مأموریت (نزدیک‌ترین واجد شرایط) با **شمارش معکوس مهلت**
۳. پذیرش → تحویل از فروشگاه با **کد روی بسته** → حرکت → تحویل با **OTP مشتری**
۴. رد/مهلت گذشته → تعویض خودکار با پیک بعدی (پس از سقف تعداد، مأموریت FAILED + ارجاع اپراتور)

## ۵. مدیر/اپراتور
۱. داشبورد: آمار واقعی (GMV جدا از درآمد)، نمودار روزانه، فروشندگان برتر
۲. صف تأیید هویت‌ها (فروشنده/پیک/تعمیرگاه) → تأیید/رد با دلیل
۳. مدیریت کاربران (نقش/غیرفعال‌سازی) — همه در گزارش ممیزی
۴. تنظیمات (کمیسیون، هزینه ارسال، مهلت‌ها) و گزارش ممیزی

## وضعیت‌های سفارش (نمای کلی)
DRAFT → WAITING_FOR_PAYMENT → PAID → SELLER_CONFIRMED → PREPARING → READY_FOR_PICKUP →
WAITING_FOR_COURIER → COURIER_ASSIGNED → PICKED_UP → IN_TRANSIT → DELIVERED → COMPLETED
(شاخه‌ها: CANCELLED، PAYMENT_FAILED، REFUND_REQUESTED/REFUNDED/REJECTED، RETURNED، DISPUTED)
