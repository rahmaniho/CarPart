# مستندات رابط برنامه‌نویسی کاربردی (API Reference)

## ۱. مشخصات عمومی و مستندات Swagger

- **پیشوند سراسری API**: `/api/v1`
- **مستندات تعاملی OpenAPI / Swagger**: `/api/docs` (در محیط توسعه فعال)
- **بررسی سلامت**:
  - `GET /health`: زنده‌بودن سرویس (`liveness`)
  - `GET /health/ready`: آمادگی پایگاه‌داده و سرویس (`readiness`)
- **سرآیندهای استاندارد**:
  - `Authorization: Bearer <accessToken>`: احراز هویت JWT
  - `Idempotency-Key: <unique-key>`: جلوگیری تضمینی از ثبت تکراری سفارش، پذیرش پیشنهاد و ایجاد پرداخت
  - `X-Request-Id`: شناسه رهگیری سرتاسری درخواست (بازتاب‌شده در پاسخ و لاگ‌ها)

## ۳. نقشه کنترلرهای اصلی بک‌اند (۲۰۹ مسیر فعال)

| دامنه | پیشوند مسیر | شرح کارکرد اصلی |
|---|---|---|
| **وضعیت سیستم** | `GET /health/ready` و `GET /api/v1/public/*` | وضعیت واقعی/آزمایشی بودن درگاه پرداخت، نقشه، تنظیمات عمومی و اطلاعیه‌های فعال |
| **احراز هویت** | `/api/v1/auth/*` | `otp/request`، `otp/verify`، `register`، `login`، `refresh`، `logout`، `me` |
| **حساب کاربری** | `/api/v1/users/me/*` | ویرایش نمایه، تغییر رمز عبور، مشاهده و ابطال نشست‌های فعال |
| **کاتالوگ و جست‌وجو** | `/api/v1/catalog/*` | دسته‌بندی‌ها، برندها، سازنده/مدل/تیپ خودرو، جست‌وجوی رتبه‌بندی‌شده و جزئیات قطعه |
| **پروفایل تعمیرگاه** | `/api/v1/workshops/me/*` | پروفایل گاراژ، آدرس‌های تحویل، خودروهای ذخیره‌شده و علاقه‌مندی‌ها |
| **استعلام قیمت (RFQ)** | `/api/v1/requests/*` و `/api/v1/seller/requests/*` | ثبت درخواست، مقایسه شفاف پیشنهادها، پذیرش پیشنهاد و ثبت/ویرایش پیشنهاد فروشنده |
| **سفارش‌ها** | `/api/v1/orders/*` و `/api/v1/seller/orders/*` | ثبت سفارش تک‌فروشنده‌ای، گذار ماشین وضعیت، تاریخچه رویدادها و ردیابی |
| **پرداخت و بازپرداخت** | `/api/v1/payments/*` | ایجاد تراکنش، تأیید درگاه، شبیه‌ساز شفاف Sandbox و مدیریت استرداد وجه |
| **لجستیک و پیک** | `/api/v1/couriers/me/*` و `/api/v1/courier/deliveries/*` | وضعیت آنلاین، موقعیت مکانی، پذیرش/رد مأموریت، بارگیری با کد ۵ رقمی و تحویل با OTP |
| **مالی و کوپن** | `/api/v1/{seller,courier,admin}/finance/*` و `/api/v1/coupons/*` | نرخ کارمزد، دفتر کمیسیون، دسته‌های تسویه شبا و اعتبارسنجی/مدیریت کوپن |
| **پشتیبانی و اعتماد** | `/api/v1/{tickets,returns,reviews,notifications}/*` | تیکت، پرونده مرجوعی، امتیازدهی پس از خرید و صندوق اعلان‌ها |
| **مدیریت کل** | `/api/v1/admin/*` | داشبورد اجرایی، گزارش روزانه GMV/درآمد، صف احراز هویت، تنظیمات و لاگ حسابرسی |

اسکریپت خودکار `npm run check:contract` در هر بار ساخت و اجرای CI بررسی می‌کند که ۱۰۰٪ مسیرهای فراخوانی‌شده در فرانت‌اند دقیقاً متناظر با مسیرهای کنترلر بک‌اند باشند.
