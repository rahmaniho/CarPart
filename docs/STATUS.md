## ⚠️ آزمایشی/Sandbox (صادقانه علامت‌دار)
| بخش | وضعیت |
|---|---|
| درگاه پرداخت | **Sandbox** (امضای HMAC داخلی) — Zarinpal پیاده‌سازی اما بدون merchant id refuse می‌کند |
| نقشه/فاصله/ETA | **تخمینی** (`mock`) — `/health/ready` = degraded؛ adapter نشان/OSRM آماده اتصال |
| پیامک/ایمیل | **شبیه‌سازی** (`isSimulated: true`) — ارائه‌دهندگان کاوه‌نگار/SMS.ir رابط دارند |
| ذخیره‌سازی فایل | محلی (local disk) |
| داده دمو | فقط با `SEED_DEMO_DATA` در توسعه |
